# BookNest – Book Shop Management System

A bookshop web application built with **Python (Flask)** and **MySQL**.

## Features
- Browse, search and filter books by genre, price and rating
- Shopping cart and printable invoices (5% tax, staff discounts)
- Live stock tracking with low-stock alerts
- Admin dashboard with revenue chart and best-sellers
- Role-based login (admin / staff)
- Auto-generated SVG book covers

## How to run
1. `pip3 install -r requirements.txt`
2. Create the database: `mysql -u root < schema.sql`
3. Start the app: `python3 app.py`
4. Open http://127.0.0.1:5000

Staff logins: admin / admin123, staff / staff123
